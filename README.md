# Centuries-Of-Chess
A Chess Simulator which shows what historical games used the same moves as the player

The site will search for games which made the same moves as the current board, then show statistics of 
previously played games from a number of different datasets (Elite Lichess Database and Caissabase).

Included is a Parser I made to sort through the multi-file dataset stored in the ELite Lichess Database,
It seperates the required information for my website but can easily be changed to gather different pieces of
information.


Frameworks I used:
jQuery: https://jquery.com/download/

chessboard.js: https://chessboardjs.com/?utm_source=chatgpt.com

Chess.js: https://github.com/jhlywa/chess.js/tree/master
